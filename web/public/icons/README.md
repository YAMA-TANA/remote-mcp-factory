# PicoSvc icon family

Original hand-written, dependency-free SVG icons. `picosvc.svg` is the suite logo; the other 16 files correspond to the service slugs. Each has a 64 × 64 viewBox with the same dark/green visual system and scales without rasterization. All files are usable independently as `<img src="/icons/shot.svg" alt="Screenshot" />` or as normal SVG assets. React UI renders matching inline vectors from `web/app/components/ServiceIcon.tsx` so the icons do not need image loading to appear. The Next.js app favicon is `web/app/icon.svg`.

These SVGs are hand-authored code, not image-generation output.
